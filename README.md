# prey-predator-simulation
##Ovverview
A Python project simulating the evolution of predator and prey populations over time. The simulation models population dynamics through interactions between both species and visualizes their evolution using graphs, revealing oscillatory patterns similar to those described by the Lotka–Volterra equations.
##Results
At the end of the simulation, a graph displays the evolution of both populations over time.

The results illustrate cyclical population dynamics: prey populations increase when predator pressure is low, while predator populations subsequently grow as food becomes more abundant. As prey populations decline, predator populations eventually decrease as well.

These patterns resemble the oscillatory behavior described by the Lotka-Volterra equations.
